# 🚀 GUÍA RÁPIDA - AGUA VIDA

## 5 Pasos para Empezar

### 1. Obtén Credenciales Firebase
```
1. https://console.firebase.google.com
2. Nuevo proyecto → "Agua Vida"
3. Configuración → Cuentas de servicio
4. Descarga clave privada (JSON)
```

### 2. Actualiza .env
```bash
# /backend-node/.env
FIREBASE_PROJECT_ID=tu-valor-aqui
FIREBASE_PRIVATE_KEY=tu-valor-aqui
FIREBASE_CLIENT_EMAIL=tu-valor-aqui
```

### 3. Instala Dependencias
```bash
cd /home/roque/Agua-Vida/backend-node
npm install

cd /home/roque/Agua-Vida/front-end
npm install
```

### 4. Inicia Todo
```bash
cd /home/roque/Agua-Vida
bash start.sh
```

### 5. Abre en Navegador
```
http://localhost:3000
```

## Crear Reporte

1. Regístrate en `/register.html`
2. Inicia sesión en `/login.html`
3. Ve a `/reportar.html`
4. Completa 4 pasos:
   - Información (título, tipo, descripción, gravedad)
   - Ubicación (mapa)
   - Fotos (opcional)
   - Resumen (confirmar)
5. ¡Enviado! Verás en `/mapa.html`

---

## Validaciones

| Campo | Regla |
|---|---|
| Nombre | Min 3 caracteres |
| Email | Formato válido |
| Contraseña | Min 8 caracteres |
| Título reporte | Min 5 caracteres |
| Descripción | Min 20 caracteres |
| Fotos | Max 5MB, solo imágenes |

## Errores Comunes

| Error | Solución |
|---|---|
| "Backend no activo" | Inicia backend en otra terminal |
| "Usuario incorrecto" | Revisa .env está completo |
| "Fotos no suben" | Backend debe estar activo |
| "Formulario no responde" | Abre F12, revisa Console |

## API Endpoints

```
GET    /api/health                 ← Verificar servidor
POST   /api/auth/register          ← Crear cuenta
POST   /api/auth/login             ← Iniciar sesión
GET    /api/reportes               ← Ver todos
POST   /api/reportes               ← Crear reporte
GET    /api/reportes/:id           ← Ver uno
PUT    /api/reportes/:id           ← Editar
DELETE /api/reportes/:id           ← Eliminar
GET    /api/usuarios/:uid          ← Ver perfil
PUT    /api/usuarios/:uid          ← Editar perfil
```
